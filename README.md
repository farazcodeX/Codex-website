# CODEX

Faraz Nourinia's static portfolio. Open through a local HTTP server (`python3 -m http.server 8000`). No build step is required.

Pages: Home, Work, NeonBook, About and Contact. The physical NeonBook shelf uses five supplied covers. All project copy is based on owner-supplied facts and the recorded project sources.

Edit `SITE_LINKS` in `app.js` to configure verified social/contact destinations. Unconfigured channels remain visibly disabled.

See DEVELOPMENT.md, DESIGN_SYSTEM.md and CHANGELOG.md for architecture, validation and the latest design audit.
